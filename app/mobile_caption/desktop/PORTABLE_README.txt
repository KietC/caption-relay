Caption Relay portable folder

EN: Extract the entire folder before running CaptionRelayCaptions.exe. This software reads existing Xiaomi native captions; it does not record audio or run ASR. Configure a new public-fork identity and enable the user's accessibility service. Use the manager for start/stop and private migration. Keep signing keys, pairing codes and caption history local. See the repository English setup guide.

中文：完整解压后运行CaptionRelayCaptions.exe。本软件读取小米原生字幕，不录音、不运行ASR。公开分支需要新的应用身份和配对，用户自行启用无障碍。通过管理器启停和私密迁移；签名、配对码和字幕历史仅保留本地。见仓库中文配置教程。
